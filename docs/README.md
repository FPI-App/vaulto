# Documentación interna del repo

Documentación técnica que vive **junto al código** de Vaulto: decisiones de arquitectura (ADRs), runbooks y notas operativas que cambian al mismo ritmo que el repo.

> La documentación de **producto** (brief, análisis de mercado, brandbook, roadmap) vive en el repo aparte [`docs`](https://github.com/FPI-App/docs), no aquí.

## Contenido

- `decisiones/` — Architecture Decision Records (ADRs). Una decisión, un archivo, numerado.
  - `0001-repo-mono.md` — por qué Vaulto es un solo repositorio.

Ver también `../ARQUITECTURA.md` (contrato técnico del esquema y la sincronización).
